# 媒体生成

- [任务 API](../task-api.md) — 对接提交、轮询和取媒体地址，查完整请求字段、模型、响应示例和兼容规则时读。
- [生图](image-generation.md) — 调用 `generate_image`，理解每日项目、参考图、模型参数、结果数组和会话恢复时读。
- [Canvas 视频](canvas-video.md) — 调用 `generate_video`，选择全能参考或首尾帧、上传或复用素材，以及定位并发生成问题时读。
- [项目分镜视频](project-video.md) — 调用 `generate_video_project`，查项目、集、分镜、准备队列或子进程时读。
- [运行依赖与任务数据](../operations/runtime-and-data.md) — 配置团队风格、超时，或判断重启后任务状态时读。
